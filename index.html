The one you can actually play

VOIDBREAKER

A twin-stick arcade roguelite in pygame-ce. Survive escalating waves, draft perks that compound, and break the Monolith every fifth wave.

The game ships no art, no audio and no font files. Every sprite is drawn with pygame.draw and gfxdraw, every glow and nebula is synthesised through numpy into a Surface, the soundtrack and effects bank is DSP written from scratch and handed to pygame.mixer as raw sample buffers, and the type is set in whatever monospace face the machine already has. The screenshots below are the only images in the repository, and the game never loads them.

It runs in a browser as the same Python compiled to WebAssembly with pygbag. Browsers have no hardware SDL renderer, so the web build starts with bloom and scanlines off; the desktop build is the faster one.

Findings

001   2026-08   FOUND NOTHING
Apparatus   ATLAS / atlas-dartboard

5,423 strategies, and the best one is worse than luck

I ran every variant through Deflated Sharpe, PBO/CSCV, White's Reality Check, Hansen's SPA, and BH–FDR on SPY, 1993 to 2026.

The best variant scored 1.34. Searching 5,423 times through pure noise is expected to produce a best of about 1.74. The winner did not clear the bar that randomness alone sets, so there is no strategy here to report, and reporting that is the result.

One variant did clear it, and it was a bug. gap_fade was reading close_to_open[t], which is the exact return it was trading. Every statistical test passed it. The fix was not statistical: nothing in the gauntlet can see an anchor sitting on the outcome, so the guard has to be structural and sit upstream of the search.

002   2026-07   UNDERPERFORMED
Apparatus   ATLAS / atlas-overnight

The overnight edge is real and still not worth trading

Across 5,443 nights of SPY from 2005, the filtered overnight track returns 3.09% a year at Sharpe 0.66. Holding the index returns 10.95% at Sharpe 0.64.

The Sharpe is a hair better and the drawdown is far shallower, and neither fact rescues it: the strategy makes a third of the money and is fragile to costs. It sends no orders.

A consecutive-loss breaker in the same system locked the track out of 191 of 250 sessions before I found it. The scorecard caught that, not the backtest.

My own README overstates my own work

The front page of ATLAS describes it as a Goldman Sachs institutional quant toolkit running 16 specialized AI agents, and reports a $159,554 balance.

None of the three holds up against the repository it describes. The balance is a paper account. "Institutional" measures nothing. The agent count counts files.

The subpackages already contradict it: the dartboard search above reports that nothing survived correction, and the overnight track reports a strategy that loses to buy-and-hold. Both were written before that README and are more careful than it is.

This entry is the correction. The original text stays where it is, struck rather than deleted.
